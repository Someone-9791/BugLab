PYTHONDEBUGUIENV - QUICK START GUIDE

START THE UI
=============

Option 1: Automatic (Recommended)
  ./RUN_UI.sh

Option 2: With Testing
  ./TEST_UI.sh

Option 3: Manual
  source ~/ml/bin/activate
  python3 test_ui_pyqt.py

VERIFY IT'S RUNNING
===================

Check process:
  ps aux | grep test_ui_pyqt

View live logs:
  tail -f /tmp/pythondebuguienv.log

WHAT YOU'LL SEE
===============

1. Terminal shows startup messages
2. PyQt6 window appears with:
   - Problem description on left
   - Code editor on right
   - Buttons: New Problem / Submit Fix / Reset Code
   - Connection status (top right)
3. Window stays open indefinitely
4. All buttons work

HOW TO USE IT
=============

1. Click "New Problem" to load a debugging problem
2. Read the description and buggy code
3. Fix the code in the editor
4. Click "Submit Fix" to test your solution
5. See results with test score and LLM feedback
6. Click "New Problem" to try another problem

TROUBLESHOOTING
===============

If UI doesn't appear:
  1. Check server: curl http://localhost:8000/health
  2. Check logs: cat /tmp/pythondebuguienv.log
  3. Try ./TEST_UI.sh

If UI closes:
  - Check /tmp/pythondebuguienv.log for errors

If buttons don't work:
  1. Verify server is running
  2. Check connection status (should be green)
